# 这个文件夹是模板，别在里面写稿

## 新建一篇论文：三步

1. **在 Finder 里复制这个 `_template` 文件夹**，粘贴到旁边，改名为你的新论文，例如 `paper-3`。
   （选中文件夹按 `Cmd+C`、`Cmd+V` 就是"复制副本"，不要用"制作替身"。）

2. **删掉副本里的这个说明文件和 `RELEASES.md` 里旧的记录**（如果有）。

3. 打开 **GitHub Desktop** → 菜单 `File` → `Add local repository...` → 选刚建好的 `paper-3`。
   它会自己认出这是一个 Git 仓库，显示 "1 commit"。

## 然后就能写了

- 在 MarkText 里打开 `paper-3/manuscript`，从 `01-intro.md` 开始
- 填 `assets/metadata.yaml` 的标题和作者
- 导出：`cd` 进去跑 `bash build.sh est`（或 wr / jhm / cej / nature）

## 注意两件事

- **不要复制一个正在写的论文仓库**（比如 paper-1），那会把它的历史一起带过来。
  只用这个 `_template`。
- 这个 `_template` 本身不要提交新内容，它是"母版"。改配置（比如加一个期刊）
  时改这里和 `paper-1` 两处即可。
- 想删掉某篇论文，直接删文件夹就行，不影响别的。

## 命令行党的做法

不想用 Finder 的话：

```bash
cdp paper-1
bash new-paper.sh paper-3
```

## 文献引用

### 1. 把文献放进 refs.bib

`manuscript/refs.bib` 已经建好了，就放在正文旁边，只是现在是空的。

用 Zotero 填：

> Zotero 里选中文献 → 右键 `Export Items` → 格式选 **BibTeX** → 存成
> `manuscript/refs.bib`（覆盖原文件）

每篇论文一个 `refs.bib`，互不干扰。改文献后重新导出覆盖一次即可。

### 2. 正文里怎么引用

| 写法 | 效果 |
|---|---|
| `[@bai2025]` | 正式引用（格式由期刊 CSL 决定） |
| `[@bai2025; @chen2026]` | 一次引两条 |
| `@bai2025 指出……` | 叙述式引用：作者作为句子成分 |
| `[-@bai2025]` | 只显示年份，不重复作者（接在作者名后） |

**key 从哪来**：打开 `refs.bib`，每条开头 `@article{key,` 里那个词就是 key。

写错了不会静默出错——`fail-if-warnings` 会让导出直接失败并提示
`citation ... not found`。

### 3. MarkText 里不会渲染

编辑时看到的就是 `[@bai2025]` 这串原文，**这是正常的**。
Markdown 里没有"引用预览"这回事，只有跑 `bash build.sh` 之后，
Word / LaTeX 里才会变成正式标注和参考文献列表。

### 4. 换期刊，引用格式自动跟着变

| 期刊 | 正文标注 | 列表样式 |
|---|---|---|
| EST (ACS) | 上标数字 | `(1) Bai, X.; Zhang, L. …` |
| Nature | 上标数字 | `1. Bai, X. & Zhang, L. …` |
| WR / JHM / CEJ | 方括号 `[1]` | `[1] Bai X, Zhang L, 2025. …` |

一条引用都不用改。

### 5. 参考文献标题

列表标题由 `assets/export-common.yaml` 里的
`metadata.reference-section-title` 控制，默认是 `References`。
学位论文里是 `参考文献`。
